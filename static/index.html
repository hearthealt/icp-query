字段说明

字段类型说明
successbool请求是否成功
keywordstring查询关键词
foundbool是否查到备案信息
countint备案记录数量
recordsarray备案记录列表
domainstring域名或应用标识
unitNamestring主办单位名称
naturestring单位性质（企业 / 个人等）
mainLicencestring主体备案号
serviceLicencestring服务备案号
updateTimestring审核通过时间
errorstring失败时的错误信息
elapsed_msint查询耗时（毫秒）

批量接口返回 { total, succeeded, failed, concurrency, elapsed_ms, results[] }， 其中 results[] 每项结构与单条查询的 data 一致。 service_type：1 网站、6 APP、7 小程序、8 快应用。
